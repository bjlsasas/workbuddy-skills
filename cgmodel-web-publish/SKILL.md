# CG模型网（cgmodel.com）模型上架 SOP

## 适用场景

把本地「CG 模型网上传包」目录（结构：`附件/*.zip` + `预览图/01…08.jpg` + 根目录 fbx + `上传参数表.md`）通过商户后台逐条上架。
配套：`cgmodel-upload-package` skill 负责**准备**上传包；本 skill 负责**发布**。

**核心机制（必须记住）**：CG模型网是**单条作品表单**，一个包填一次表 → 一条作品。与爱给网「多选 zip 自动生成多条」完全不同。127 个包 = 127 次完整填表。

## 环境前提

- Windows + 双屏；主屏 `DISPLAY1 (0,0,1920,1080)`。以下坐标均为主屏**屏幕坐标**。
- Chrome 已登录 CG模型网商户账号（本机账号「胖胖的吃货」）。
- 工具：`mcp__windows-mcp__*`（Snapshot / Screenshot / Click / Type / Scroll / PowerShell）。
- 图片**可以正常读图**；小控件用 PowerShell 区域截屏放大 2× 后 Read 核对最可靠。

## 开工前环境自检（必做，尤其无人值守的定时任务）

本 SOP **依赖物理鼠标/键盘 + 截图**。若工作站处于**锁屏**状态，`mcp__windows-mcp__*` 会整体报
`OSError: screen grab failed`，`Click/Type` 全部静默失效，**整条流水线直接作废**。

30 秒自检（Python + ctypes，不依赖 windows-mcp）：

- `OpenInputDesktop(...)` 返回 0（err=5）、`GetForegroundWindow()` 返回 0、`SetCursorPos` 返回 0 且光标一直停在 (0,0)
  → **已锁屏**。此时唯一能做的是**只读巡查**（读 UIA 树判断审核状态），
  填表发布必须等桌面解锁后再跑。降级手法见 skill `windows-uia-fallback-when-locked`。
- 另注意：`mcp__windows-mcp__*` 连接器偶发长时间停在下发状态，先用 `ToolSearch` 确认工具确实注册了。

## 站点反爬（重要）

cgmodel.com 有 WAF「安全环境验证」页（`challenge.cgmodel.com/?return_to=…`）。
**Chrome 里点「重新加载」或任何 `curl` 直连都会命中它**，命中后页面 DOM 不再暴露给 UIA。
所以：巡查时**尽量只切标签页（`SelectionItemPattern` / 聚焦+空格），不要刷新**；
若已进入挑战页，用 Chrome「返回」按钮连续回退几次即可退出。


## 入口

1. 商户后台 `https://www.cgmodel.com/business/index.html`
2. 左侧「发布模型」→ `https://www.cgmodel.com/works/model-publish-v.html`
3. URL hash 会随步骤变化：`#drafts=<草稿ID>&next=1|2`。`next=1` 在第 1 步、`next=2` 在第 2 步。

## 第 1 步：上传模型与配图

必填：**上传预览图\***、**上传线框图/点线面截图\***、**模型许可范围\***、**上传文件附件\***。

| 操作 | 位置 / 做法 |
|---|---|
| 上传预览图 | 点左侧占位框「点击或拖拽上传预览图」→ 弹出 `#32770` 文件框 → 用 `Set-Clipboard` + `SendKeys '^a','^v','{ENTER}'` 填完整路径回车。多张图可分多次选 |
| 上传线框图/点线面截图 | 同上，第二个占位框。预览图 05_室内人视B 之后是 06_线框透视 / 07_线框顶视 / 08_视口点面统计，三张一并选 |
| 模型许可范围 | 选「**没有**」（圆点在最左，红点=选中）。右侧文案「游戏，电影，广告等所有授权允许的用途都能使用此模型」 |
| 上传文件附件 | 点「点击上传附件」→ 文件框选 zip（约 229 MB，上传约 1–3 分钟，进度 100% 显示「完成」） |
| 发布模式 / 价格 | 「素材出售」+ 价格输入框填 **30**（¥）。「关闭个人授权」**不勾** |
| 文件格式 | 必须**从候选下拉里选**，手打会报「未找到匹配的文件格式」。选 `FBX(.fbx)`；再点「+ 为此附件添加更多格式」增行选 `3ds Max(.max)` |
| **格式版本（必填，易漏）** | 文本框，占位符「输入版本」。FBX 行填 `2020`、3ds Max 行填 `2025`（本批全部包通用）。**`^v` 粘贴经常不生效**，用「模拟点击 → `^a` → `{DEL}` → `SendKeys('2020')`」直接键入数字最稳 |
| **渲染器（必填，易漏）** | **只有一行格式时页面上没有渲染器控件**；点「+ 为此附件添加更多格式」增出**第二行**后，渲染器才出现在第二行右侧，点它选 **Default**（Max 默认扫描线） |
| 下一步 | 「下一步>」在第 1 步底部操作栏。**注意**：点附件区后页面会自动滚动、按钮移出视口，需再 `Scroll down ×5` 才能看到（本机约 (1177,875)） |

> **校验拦错**：漏填格式版本 → 点发布弹「操作失败 / **请输入附件格式版本**」；漏选渲染器 → 「操作失败 / **请选择附件渲染器**」。二者都只在第 1 步可改。

## 第 2 步：填写模型介绍

字段来源全部取包的 `上传参数表.md`。

| 字段 | 值 / 做法 |
|---|---|
| 标题\* | 如「轨道交通1号线双龙大道站 车站建筑模型」（5–30 字，用空格隔开） |
| 分类\* | 「建筑」+「公共设施」（两个下拉） |
| 模型风格\* | 「写实」 |
| 面数\* / 点数\* | 121465 / 153135（纯数字） |
| 布线类型\* | 「四边形」 |
| 关于UV\* | 「已展开，不重叠」 |
| 勾选项 | 勾 **有材质**、**有贴图**；不勾 PBR/绑定/动画/未塌陷/3D打印/插件/AI内容 |
| 模型说明\* | 粘贴参数表正文（约 250 字） |
| 关键词\* | 见下方「关键词处理」 |
| 上传封面\* | 点「展示封面」区 → 选 `预览图/01_室外斜俯视.jpg` → **弹「编辑封面」裁剪层 → 再点蓝色「提交」** 才生效 |
| 同意条款 | 勾「我已阅读并同意…」（**默认未勾**，不勾无法发布） |

### 关键词处理（重要）

平台会给关键词框**预填一批无关热门词**（本机实测出现过：停机坪细模 / 简模沥青路 / 微观城市底模 / 城市道路沙盘 / 藏式跑马场细模 / 模块化拼接道路 / 飞机跑道军事基地 …）。必须清理。

- 每个标签右侧有个仅 named `提交` 的 × 按钮（21×20）。取坐标用 UIA 过滤 `ControlType=Button, Name='提交'`。
- **删除顺序必须从最后一个要删的往前点**：删后面的标签不会让前面的标签位移，所以预取的坐标全程有效；反之会错位。
- 地铁站类包的保留关键词建议：`地铁站` / `车站建筑模型` / `轨道交通` / `交通设施` / `建筑模型`。
- 批量删除可用一段 PowerShell 的 `SetCursorPos + mouse_event` 循环（每点间隔 450–500 ms）。

### 底部操作栏（第 2 步）

`查看审核规则` `预览` `上一步` `暂存草稿箱` `发布`

> **⚠️ 这一栏的 Y 坐标随滚动位置变化，不要沿用固定值**。第 2 步填完可能位于 y≈839，也可能在 y≈934（差 ~95px）。**每次发布前必须重新截图确认当前 Y**，否则点「发布」毫无反应。判据：先看「我已阅读并同意…」那行文字的 Y，操作栏在其下方约 150px。

### 「编辑封面」裁剪层（实测踩坑）

点「上传图片封面」→ 选图 → 弹出**「编辑封面」裁剪弹窗**（左裁剪框 + 右「封面预览图」+ 下方蓝「提交」/「取消」）。

- **弹窗是自定义层面板，UIA 报出的坐标与画面观感可能差 ~80px**。用 mcp `Click` 或 `mouse_event` 点「提交」**都会失效**（点了没反应、弹窗不关）。
- **唯一可靠解法：用 UIA `InvokePattern` 触发**：
  ```powershell
  # Button Name='提交' 且 BoundingRectangle.Y > 600 的那个（页面上另有 5 个关键词标签的 × 也叫「提交」，Y≈146，别选错）
  $p = $e.GetCurrentPattern([System.Windows.Automation.InvokePattern]::Pattern); $p.Invoke()
  ```
  本批第 4 条（经天路）就卡在这里，Invoke 后立即成功关闭、封面缩略图出现。
- 封面成功判据：`上传封面` 区出现缩略图 + 右侧出现「点击上传视频（非必选）」+ 下方文案变「为了吸引用户，您还可以上传一个视频作为封面」。

## 第 3 步：发布

1. 确认同意条款已勾。
2. 点「发布」(1240,839)。
3. 成功 → 弹窗「**提交成功，请等待审核…**」，含「预览模型」「回模型列表」。点「回模型列表」→ `https://www.cgmodel.com/business/index.html#model?verify=0`。
4. 在「**待审核**」tab 核对卡片：封面缩略图、标题、**￥30.00**、日期。平台提示管理员 1–3 个工作日审核。

## 绝对不要做的操作

- **不要点「预览」按钮**，也不要点步骤条上的「1.上传模型与配图」「发布，等待审核」链接：会触发 Chrome `beforeunload`（「离开此网站？系统可能不会保存您所做的更改」），有丢数据风险。（步骤条链接实测点了也无响应。）
- **回上一步请用底部「上一步」**，回下一步用第 1 步底部的「下一步>」——SPA 内切换，不刷新、数据全保留。
- 不要在文件管理器 / Blender 窗口抢焦点时操作——Chrome 焦点会丢，UIA 树也会被其它窗口的元素挤爆（500 元素上限截断）。**操作前先把 Chrome 切到前台**。

## 读屏技巧（本机验证有效）

UIA 只 dump 有 Name 或 Value 的元素，页面控件太多时会被其它窗口挤掉，所以：

```powershell
# 只取 Chrome 的页面元素（含屏幕坐标，Click 直接用）
Add-Type -AssemblyName UIAutomationClient; Add-Type -AssemblyName UIAutomationTypes
$root=[System.Windows.Automation.AutomationElement]::RootElement
$cond=New-Object System.Windows.Automation.PropertyCondition([System.Windows.Automation.AutomationElement]::NameProperty,'<Chrome 窗口标题>')
$win=$root.FindFirst([System.Windows.Automation.TreeScope]::Children,$cond)
$all=$win.FindAll([System.Windows.Automation.TreeScope]::Descendants,[System.Windows.Automation.Condition]::TrueCondition)
foreach($e in $all){ $ct=$e.Current.ControlType.ProgrammaticName -replace 'ControlType.',''; $n=$e.Current.Name; $r=$e.Current.BoundingRectangle }
```

- 页面滚动后，视口外元素会带**负 Y 或 >1080 的 Y**。所以：**只取当屏可见元素**就用 `Y=430..1035` 过滤；**要拿全量列表**（如清点已上架作品）必须**去掉 Y 过滤**，只按 `ControlType=Hyperlink` 排除「编辑 / 专辑 / 更多 / 修改价格 / 官方客服 / 官方群 / 意见反馈 / 充值」来筛标题。
- 右下角常有 **ToDesk 悬浮窗**遮挡卡片。**不要点「断开」**（会打断用户的远程会话），改用 UIA 文本绕开。
- 小控件核对：`System.Drawing.CopyFromScreen` 截区域 → 2× NearestNeighbor 放大 → `Read` 该 PNG。

## 开工前先去重（必做）

账号里通常已有历史作品，**务必先清点再动手**：商户后台 → 模型管理 → 四个标签页 `已上架 / 待审核 / 草稿箱 / 未通过` 逐个读标题。

- 标签页带计数，如 `已上架 (15)`、`草稿箱 (3)`；标签 x 坐标会随计数位宽漂移，**每次用 UIA 取 `Y≈232` 的 Text 中心坐标**再点。
- 已上架的标题可能有多套命名风格（`轨道交通1号线_XX站_车站建筑模型` / `南京地铁1号线XX站车站建筑模型` / `地铁站——XX`），**按站点名去重，不能按标题串匹配**。
- 草稿箱里可能有**空草稿**（无标题、只有 CG 占位图），忽略。
- 注意「模型管理」之外还有「作品管理」，两者不同；模型上架只看「模型管理」。

## 文件对话框（`#32770`）操控

`Add-Type` 内联 C# 用 `EnumWindows/EnumChildWindows/GetClassName/GetWindowText/GetWindowRect` 定位「文件名」Edit（中心约 (694,477)）与 `ToolbarWindow32` 地址栏；`Set-Clipboard` 后 `SendKeys '^a','^v','{ENTER}'` 提交路径。若对话框不弹，先 `ctrl+r` 刷新页面再点按钮（页面异常态会导致点击无响应）。

## 实战坑位补充（2026-10-12 批量首条验证）

1. **预览图多选会漏图**：一次粘贴 5 条路径（空格分隔、各自带引号）实测只上 **4 张**。
   - **推荐解法（已验证 3/3 成功）**：拆成 **3+2 两次**对话框——第一次粘 `01 02 03`，第二次粘 `04 05`，每次 ≤3 张不掉图，总 5 张且顺序正确。
   - 兜底：点占位框单传缺失那张 → 截图数缩略图；变 5 张即齐，变 6 张说明重复。
1b. **线框图（06/07/08）一次粘 3 条稳定成功**（3 张未超过阈值）。
1c. **格式自动识别时有时无**：附件传完若两个格式行已自动出现（FBX + 3ds Max），只需补「格式版本」「渲染器」；若只出现一行，才需点「+ 为此附件添加更多格式」。
2. **第 2 步「模型说明」「关键词」是自定义组件**：UIA 里表现为 `Group`，**没有 ValuePattern**，只能键盘输入。
   - 点击必须落在框**内部**；点在上下边界 1px 会失焦、粘贴静默失败。判据：看「还可以输入 N 个字符」计数是否变化。
   - **说明框会随内容撑高**，填完说明后「关键词」框下移 → 必须**重新用 UIA 取「关键词：」标签下方那个 Group 的坐标**再点，否则关键词会被追加进说明框（本次踩过，需 `^a` 全选重贴说明来纠正）。
3. **中文一律走剪贴板**（`Set-Clipboard` + `SendKeys('^v')`）；纯数字/英文用 `SendKeys` 直敲更可靠。
4. **下拉候选的真实落点常比控件低 40–60px**（如「模型风格」的「写实」在标题下方约 50px）。**先区域截图放大 3× 定位再点**，别按控件矩形猜。
5. **分类下拉是一行两列**：一级分类列表分左右两列，「建筑」在**右列**；选完一级后二级可用，「公共设施」在二级列表首项。
6. **第 1 步「模型许可范围」单选**：圆点在文字左侧约 20px、与文字基线平齐（本机约 **(456,571)**）。**首次点击经常只聚焦、不选中**——需**连点两次**（间隔 300–400ms），或直接对 `ControlType=RadioButton` 用 `SelectionItemPattern.Select()`。选中标志：圆点变红色实心 + 右侧出现「游戏，电影，广告等所有授权允许的用途都能使用此模型」。**每次都要放大截图复核**，本批 4 条里有 3 条第一次都没选中。
7. **同意条款默认未勾**，发布前必检。
8. **发布成功判据**：出现「提交成功，请等待审核…」+「回模型列表」；随后必须在模型列表「待审核」里核对标题 / ￥30.00 / 日期。
9. **`#32770` 文件对话框**：本机 PowerShell 枚举脚本有时抓不到（返回空），但对话框其实已弹出 → **以截图为准**，别因为枚举为空就重复点击。

## 单条耗时基线

试跑实测（含摸索）约 25 分钟/条；SOP 固化后预计 4–6 分钟/条。127 条约 29 GB。2026-10-12 批量首条（奥体东）用时约 23 分钟，仍属「边跑边摸坐标」阶段。2026-10-13 续跑两条：南大仙林校区约 25 分钟（含环境故障排查）、上海路约 18 分钟。

## 实战坑位补充（2026-10-13 批量续跑验证）

1. **环境工具链**：本机 Git Bash 的 coreutils 会整体失效（`ls` / `cat` / `grep` / `head` 全部 not found，`cat > file` 也写不进去）→ **统一改用 PowerShell 工具**，不要依赖 Bash。
2. **PowerShell 工具不回显 stdout**（最高频的坑）：命令返回 exit code 0 但 stdout 为空 → 一律把结果 `Out-File` / `Set-Content` 到临时文件（如 `_env.txt` / `_ls.txt`），再用 **Read 工具**读取。所有"取结果"类操作都走这条通路。
3. **自定义下拉的候选落点普遍比标注位置低 40~60px**：一级分类 / 二级分类 / 模型风格 / 布线类型 / 关于UV **全部**如此。**必须先 `CopyFromScreen` 区域截屏并放大 2~4× 确认真实坐标再点**；按 Snapshot 的文字标注位置点会静默失败（点了毫无反应，容易误判为"页面卡住"）。
4. **「+ 为此附件添加更多格式」按钮**：标注 y≈912，真实可点中心 **y≈940**（低约 28px）。
5. **第二行「格式版本」输入框**：占位符文字在 y≈959，真实输入框中心 **y≈986**（低约 27px）；点在 y≈955 只会选中页面文本、不会聚焦输入框。
6. **关键词框可能没有预填热词**（2026-10-13 上海路即为空框）：先 UIA 统计 `ControlType=Button, Name='提交'` 的数量，**=0 表示无预填**，直接输入 5 个词即可，省掉整轮清理。
7. **裁剪弹窗「提交」按钮**：UIA `InvokePattern` 命中坐标固定 **(549,720)**，与画面观感 (693,745) 差约 80px；再次验证鼠标点击 / `mouse_event` 对该自定义层无效，只有 Invoke 有效。
8. **点「下一步>」前先点一次页面空白处**：否则会因前序 `^a` 残留的文本选中而弹出 Chrome 的「AI搜索 / 翻译 / 复制」浮动菜单，正好挡住按钮。
9. **第 2 步进第 1 步的"下一步>"位置**：第 1 步底部按钮会被附件区挤到视口外，需 `Scroll down ×5` 后位于约 **(1177,875)**。
